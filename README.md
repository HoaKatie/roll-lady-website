# Roll-Lady

A simple pre-launch landing page for **Roll-Lady**, a Vietnamese-inspired folding mat designed for making fresh spring rolls.

## About

Roll-Lady was inspired by Vietnamese fresh spring rolls (`gỏi cuốn`) and the tradition of gathering around fresh herbs, vegetables, and ingredients to make and share food together.

The website introduces the idea behind the product and allows visitors to join the Roll-Lady mailing list for future product updates.

## Website

This is a static HTML/CSS website designed to be hosted for free using **GitHub Pages**.
